# RehabRhythm

AI-Assisted Rhythm Rehabilitation Training System

## Overview
RehabRhythm is a desktop rehabilitation prototype that combines
computer vision, rhythm-based interaction, and rule-based feedback.

## Features
- Webcam-based hand tracking
- HIT / TAP / HOLD gesture interaction
- Rhythm-based training
- Training results and history
- Rule-based performance analysis
- Elderly-friendly interface design

## Technologies
- Python 3.11
- Pygame
- OpenCV
- MediaPipe
- NumPy / Pandas

## Installation
pip install -r requirements.txt

## Run
python game.py

## Project Status
Bachelor Thesis prototype.

This system is intended for research and prototype demonstration only.
It is not a medical device and does not provide medical diagnosis.
